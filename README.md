# Просмотрщик котов 🐱

Простая программа на Python, которая скачивает случайное изображение кота из интернета и отображает его.

## 📋 Требования

- Python 3.6 или выше
- Библиотеки: requests, Pillow (PIL)

## 🔧 Установка

1. Склонируйте репозиторий или скачайте файл `cat_viewer.py`

2. Установите необходимые библиотеки:

```bash
pip install requests Pillow
